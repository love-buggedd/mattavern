This is the Mat Tavern repository and contains all of its assets for open-source usage and inspection.

## Overview
All files are hosted on `sites.google.com/*****.***/mattavern`

Mat Tavern is a web-porting hub that's used by my personal friends and myself. It exists to be used for its various tools, chatboxes, and especially its web-ported game catalogue.

### Features
- Games Page
    > Contains externally ported games, will continue to grow if I find more ports that I haven't made.
- Wheel
    > A customizable wheel that you can spin for random selection, by default has all available games.
- Chatroom
    > Allows other Mat Tavern users to communicate with you in a universal chat.

### Future Features
All of these ports will be done exclusively by me.

- Gas
    > A library of exclusively steam games.
- Groove
    > Another library for all games that aren't on steam.
- Chat Tabs
    > Allows for DMs alongside that Universal chat.

## Emulation Tools
- PEMSA
    > This includes Classic Slipways and other `.p8` games.
- Unity
- Godot
